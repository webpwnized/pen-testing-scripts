# Security Policy

## Reporting a Vulnerability
If you discover a security vulnerability in this project:

1. **Do not open a public GitHub issue.**
2. **Contact the maintainer directly** via email: [research@ellipsisinfosec.com](mailto:research@ellipsisinfosec.com).
3. Provide detailed information:
   - A description of the vulnerability
   - Steps to reproduce (if possible)
   - Potential impact

We will review your report promptly and respond with next steps.

---

## Responsible Disclosure
- Please allow us reasonable time to investigate and address the issue before publicly disclosing.
- We are committed to transparency and will publish security advisories through GitHub's [Security Advisories](https://github.com/webpwnized/pen-testing-scripts/security/advisories).

---

## Best Practices for Contributors
To help maintain security in **Pen-Testing-Scripts**:
- Avoid committing secrets, tokens, or sensitive data.
- Use environment variables or configuration files excluded from version control.
- Review dependencies before adding new ones.
- Follow the principle of least privilege in all scripts.

---

Thank you for helping us keep **Pen-Testing-Scripts** secure!
